# SMC/BATTO 기술적 분석의 약형 효율적시장가설 실증 — 전체 분석 기록

- **생성일**: 2026-06-06
- **산출 경로**(원래 작업 폴더): 본분석 `stage1/`·`stage2/`·`results/` → 이 저장소 `emh/`, 매도·벤치마크 `golden/` → `batto/`
- **핵심 연구질문**: SMC(스마트 머니 개념) 기술적 신호에 미래 수익 예측 정보가 존재하는가? = 약형 효율적시장가설(weak-form EMH) 검정. 부차적으로 매도(청산) 시점과 진입 시점의 알파 존재 여부.
- **최종 결론(1줄)**: 미시 차트패턴(SMC/BATTO)의 진입 알파 ≈ 0 (미국 시장 약형 EMH 지지). 유일하게 통계적으로 견고한 엣지는 거시 시장심리 지표(CNN Fear & Greed < 30 공포 매수).

## 2. 신호 정의 — 변수·파라미터 전부

### 2.1 공통 기반
- **ATR**: 14봉 (변동성 정규화·필터 기준)
- **스윙(swing)**: 일반 K=5 (좌우 5봉 최고/최저). 추세선만 swingK=12.
- **수익 정의**: 방향수익 = sgn × (c[j+N]/c[j] − 1) × 100. 롱 sgn=+1, 숏 −1.

### 2.2 1단계(stage1) 신호 명세 — 총 13개 (FVG 9 + OB 4)
- **FVG 9명세** = 크기필터 {몸통 2배 · ATR×1.5 · 없음} × 채움트리거 {터치 · 50% · 100%}
- **OB 4명세** = 존구간 {전체[L,H] · 몸통[O,C]} × FVG동반 {필수 · 무관}
- **타이밍**: BOS 스윙 룩백 좌우 5봉, 유효창 K=20봉, 보유 N={5,10,20}, 일봉 단일 TF

### 2.3 BATTO(golden) 신호 파라미터 — 전체
| 구분 | 파라미터 | 값 |
|---|---|---|
| 스윙 | K (일반) | 5 |
| 스윙 | swingK (추세선) | 12 |
| 채널 | W (이동평균/표준편차 창) | 40 |
| 채널 | KSD (표준편차 배수) | 2.0 |
| 채널 | 동일방향 재발생 차단 | 5봉 |
| 트리거 공통 | LOOK (탐색창·존 수명) | 50봉 |
| 추세선 | minbars (두 스윙 최소 간격) | 42 |
| 추세선 | tol (터치 허용오차) | 0.3% (0.003) |
| 추세선 | TLPEN (사이 캔들 관통 허용) | 0.5% (0.005) |
| OB | OBMULT (분출 배수) | 2.0 |
| OB | EPS (엥걸프 연속성 허용) | 0.3% (0.003) |
| OB | 필터 OB_ATR (존 폭 최소) | ATR×0.3 |
| FVG | 강한봉 몸통 배수 | 앞뒤 2배 |
| FVG | 필터 FVG_ATR (갭 최소) | ATR×0.7 |
| Trap | 탐색창 G | 20봉 |
| Trap | BR (돌파 여유) | 1% |
| Trap | NR (근접 허용) | 1.5% |
| 컨플루언스 | CW (causal 윈도우) | 5봉 |

- **OB 정의(상승)**: 음봉(c1)→양봉(c2). ①음봉종가=양봉시가(EPS 0.3%) ②양봉몸통>음봉몸통×2 ③양봉종가>음봉고가(분출). 존=음봉 몸통[종가,시가]. 하락 거울.
- **FVG 정의(상승)**: 3캔들 중 가운데 강한 양봉(몸통>앞뒤×2) + 1번 고가<3번 저가(갭). 존=[1번고가,3번저가]. 하락 거울.
- **strict 유효성(_conf_one)**: ①방향정합 ②form≤j & j−form≤50 ③무효화 안 됨(form~j 사이 종가 완전관통 X) ④진입봉 종가 관통 X ⑤꼬리 도달(overlap) ⑥숏 추가조건.

### 2.4 매도(청산) 5방식 파라미터
| 방식 | 파라미터 그리드 |
|---|---|
| 고정 N일 | N ∈ {5,10,15,20,25,30,40,50,60} |
| ATR 손익비 | 손절=ATR×1, 목표=ATR×RR, RR ∈ {1.0,1.5,2.0,2.5,3.0} |
| 반익반본 | 1차목표 ATR×mult(절반 익절·본전 이동), mult ∈ {1.0,1.5,2.0,2.5,3.0}, 최대 40일 |
| 트레일링 | best ± ATR×mult, mult ∈ {0.5,1.0,1.5,2.0,2.5,3.0} |
| 구조 기반 | 반대 OB/FVG 출현 청산, 최대 N ∈ {20,30,40,60}일 |

## 3. 분석별 결과 (시도 수 · 표본 · 수치)

### 3.1 1단계 지수 회귀 (HAC)
- **모형**: fwd_N ~ 신호더미 + vol20 + logvol, Newey-West HAC(lag=N)
- **시도 수**: 6신호 × 3시장 × 3N = **54 회귀**
- **결과**: **전부 비유의(p≥.10)**. max|t| = 1.61 (BTC, OB_A_L, N5).
- 흔적: 상승신호(FVG_L·OB_A_L) 음(−)계수, 특히 BTC·장기N. 효과크기 BTC 최대 (FVG_L N20 BTC −1.57%p vs 미국 −0.07%p).
- **판정**: 지수 수준 H1(약형 EMH 기각) 실패 = **EMH 지지**.

### 3.2 1단계 확장 (컨플루언스·방향풀링·수익성·FDR)
- H2 컨플루언스(sweep·fvg·gap2x), 방향풀링, H5 net 수익성, 기간분할, FDR 보정 — **전부 비유의**.
- FDR 통과 0건, 최소 p = .107. → 지수 수준 약형 EMH **지지 확정**.

### 3.3 2단계 개별종목 (이중 클러스터 패널 회귀)
- **표본**: 미국 79 + 한국 40 + 가상자산 22 = **141 종목**. 종목별 신호→시장초과수익→이중클러스터(날짜·종목).
- **H1 방향일치 유의 건수**: 미국 0 / 한국 3 / 가상자산 4 (각 /18) → **H3 효율성 기울기 확인(가상자산 > 한국 > 미국)**.
- **방향풀링(핵심)**:
  - FVG 가상자산 전 N 유의: N5 **+0.69%p (p<.001)** / N10 **+0.68%p (p<.01)** / N20 **+1.46%p (p<.05)**
  - FVG 한국 N5 **+0.12%p (p<.01)**
  - FVG 미국 전부 비유의 / OB(A·C)·컨플루언스 거의 비유의
- **H5 수익성**: FVG 방향조정 초과수익이 가상자산서 거래비용(왕복 0.2%) 차감 후에도 **+0.42 ~ +1.23%** 잔존. 미국·한국 소멸.
- **판정**: 약형 EMH 미국 지지, 비효율 시장(가상자산·한국)서 **FVG에 한해** 기각.

### 3.4 SMC 3종 (추세선·채널·페이크아웃, 개별종목 이중클러스터)
- 추세선: 가상자산 N10 **+0.49%p (p=.043*)**
- 채널: 미국 N10 +0.085 (p=.038*) / 가상자산 N5 **−0.43 (p=.01*)**
- 페이크아웃: 가상자산 N5·N10 **−0.76 / −1.10 (p<.005*)**
- 해석: 코인 = 단기 모멘텀(연속성). 반전계열(채널 역추세·페이크아웃)은 코인서 역행(음). 미국 거의 전무.

### 3.5 세계 퀀트전략 4종
- TSMOM·XSMOM·단기반전·MA(50/200)
- 미국: **4종 전부 비유의**(차익거래 해소).
- 한국: TSMOM·반전 한계유의 (p≈.06~.08).
- 가상자산: 단기반전 강하게 음 **−0.49 / −0.90 / −1.87%p (p<.001 ~ 1e-6)** = 단기 모멘텀.

### 3.6 펀더선택 × 하위TF
- Part A 종목선택×FVG: 한국 가치주 N5 **+0.21%p\*** / 저유동 **+0.14%p\***, 성장·고유동 비유의(+0.04). 미국 전무. 코인 광범위 유의.
- Part C 하위TF(1h FVG/OB + 일봉MA20 정렬): 미국·한국·코인 **전부 비유의(별표 0)**. → 엣지는 "낮은 TF"가 아니라 "비효율 종목".
- Combined(5종 합산 net): **전부 비유의**, 단조성 없음(부호 상쇄).

## 6. 결론

1. **약형 EMH는 미국 시장에서 강하게 지지된다.** SMC·퀀트·매도·진입 어느 차원에서도 미국 개별 차트신호의 알파는 통계적으로 0. 진입 벤치마크가 결정적: Batto 신호 − 무작위 = +0.05%p (t=0.20).
2. **비효율 시장(가상자산 > 한국)에서는 FVG에 한해 약형 EMH가 부분 기각된다.** 코인 FVG N5 +0.69%p (p<.001), 한국 가치주·저유동 FVG 유의.
3. **시장 성격이 방향을 규정한다.** 코인 = 단기 모멘텀/연속성(반전계열 역행), 미국·한국 = 약한 평균회귀.
4. **매도 시점 최적화는 알파가 아니라 베타였다.** 고정 보유 길수록 단조 증가(60일 +3.17%)는 시장 상승 드리프트일 뿐, 무작위 진입과 동일.
5. **유일하게 견고한 엣지는 거시 시장심리(CNN F&G < 30 공포 매수).** 클러스터 보정 후에도 초과 +2.61%p (t=6.66), dose-response, 6/6 연도 일관, 거래비용 차감 후 +4%대. → 정보는 개별 캔들의 기하학이 아니라 시장 감정의 극단에 있다.

**한계**: F&G 효과는 마켓 타이밍(언제)이지 종목 선택(무엇)이 아니며, 데이터가 2021~2026(2022 약세장+회복 포함)에 국한된다. 보유기간 겹침에 따른 자기상관에 HAC 미적용(dose-response·연도 일관성이 이를 보강). 개인 실전 EV 실현은 대박 의존·심리·분산 한계로 별개 문제.
