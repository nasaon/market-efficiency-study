## 2. ★검증된 엣지 (robust·진짜)

| 엣지 | 근거 | 왜 robust |
|---|---|---|
| **대형주 모멘텀(터틀)** | S&P500 +20%p·나스닥 +17%p 재검증·소형주는 실패 | 100년+ 학술검증 팩터·넓은 유니버스서 유지 |
| **시장 패닉 VIX 바닥매수** | 전 유니버스 robust·패닉40+ 압도(승률93~97%) | 시장신호라 유니버스 무관·깊을수록 이후수익↑(단조) |
| **VIX 백워데이션(VIX>VIX3M)** | 신호후1년 승률 90% vs 레벨 65% | 기간구조=급성패닉 학술신호·레벨에 차원추가 |
| **변동성 타게팅** | 22MDD 17→14%·전체Calmar 0.56→0.77 win-win | AQR 정석·고변동 노출↓·불장도 안깎임 |
| **선택 폭(유니버스 확대)** | 20종목 +5%p→60종목 +24%p 단조 | 많이서 고르면 top8이 더 예외적(편향 아님) |
| **S&P500 유니버스** | +20%p·OOS 2025 +56(손픽 -19)·규칙기반 | 큐레이션 편향↓·최근 robust |
| **국내 상대모멘텀(듀얼모멘텀 TOP5)** | 유니버스 대비 ×5.7·상대알파 +27.3%p·8/11년(슈퍼위너 제외 보수) | 모멘텀 팩터의 한국 재현·유니버스 민감도 통과·저회전이라 거래세 생존 |
| **국내 이중 공포 타점(VIX∧역배열∧RSI≤30)** | 12M 중앙 +20.1%·승률 76% vs 무작위 +4.9%/56%(n=132) | 글로벌 공포(VIX)와 개별 공포의 교집합만 진짜 바닥·같은 종목 내 비교=생존편향 무관 |

**공통점: 파라미터 튜닝이 아니라 '무상관/구조적 정보·수익원 추가'.** 이게 robust의 조건.

## 3. ★기각된 것들 (다 OOS 붕괴 — 반복 금지)

### 3-1. 청산 정교화 = 알파 아님
- **익절강화(고점 근처 익절)**: 반납%·RSI과열·익절타깃·트레일변형 등 14방법·100R×6시드. 매번 Train↑ OOS 제자리/악화. 반납15%는 종목 9중5승(동전던지기·고립 스파이크). **고점은 사후에만 보임·못 맞춤.**
- 채택안(저점이탈 절반익절+트레일2ATR·1.5N)이 robust 최선. 무한홀드=참사·전량트레일=자주끊김.
- '추세종료해도 홀드' 비교: 코인은 홀드=참사(청산 필수)·미국초우량은 홀드가 절대수익↑이나 MDD 2배.

### 3-2. 진입 필터 = 도움 0 (16지표 전수)
- 모멘텀(RSI·스토캐스틱·MACD·일목 16조합)·추세(ADX·수퍼트렌드·Aroon·Vortex·돈치안중심·CCI·PSAR)·거래량(VolSurge·OBV·CMF·MFI).
- **전부 무효 or 해로움.** RSI/스토캐스틱=돌파시 이미 참(중복)·일목/ADX/VolSurge=후행이라 진입지연으로 추세초입 놓침.
- ★원리: **터틀 돌파진입 자체가 이미 추세신호.** 확인지표 추가=중복 or 지연. 유일 유효=SMA필터.

### 3-3. 숏 = 다 실패 (마진/차입비 필요·2022 외 못 범)
- **추세추종 숏**: 강추세주 베어랠리 휩쏘로 악화(22 -5→-9%).
- **평균회귀 숏(과매수 페이드)**: 하락필터 걸면 2022만 +18%·다중하락장 OOS서 2018Q4/2020코로나 0%(빠른V급락 못 범)=단일에피소드 과최적.
- **고점 헤지 숏(롱 보유중 숏)**: 100R Train↑ OOS 0.65→0.62·4/11종목. 고점타이밍 함정.
- **X%런업 숏 연도별**: 5~20% 다 전체 마이너스·2022만+·±5%대칭이 강세장서 음의기대.
- ★결론: 하락/고점 타이밍은 어떤 형태든 robust 실패. 숏 전면 접음.

### 3-4. 구조 변형 = 무레버리지라 무의미
- **피라미딩(승자 add-up)**: 무레버리지면 초기노출 늦춤/희석·역효과(0/9종목).
- **듀얼시스템(20/55)**: 무효(1/9). 원조터틀 증폭은 선물/레버리지서 나옴·코인은 이미 1.8~2.7배급.

### 3-5. 선별/사이징 튜닝 = 엔진의존·과최적
- **모멘텀 룩백(189일 등)**: 하네스선 Calmar 2배지만 --verify(다른엔진)선 정반대(+31→+9%p)=방법론 아티팩트.
- **섹터캡(반도체)**: 쏠림↓지만 알파희생(2026 +54→-28). 집중은 모멘텀의 본질·캡=엣지와 싸움.
- **레짐필터(200MA)**: 불장만 깎여 무효(터틀 손절이 이미 하방방어).
- **z가중 사이징**: 복리69배지만 MDD64%(Calmar 동률·고옥탄일뿐).

### 3-6. 하락장 플러스 = 금 무상관만 살아남음
- **숏·국채(TLT)**: 실패(2022 주식·채권 동반하락 nowhere to hide).
- **금(GLD) 추세**: 전체+135%·무상관·유일 디버시파이어. 단 **금+원자재 슬리브는 소액엔 부담**(시장추가)→접음.
- ★2022형 하락장 '플러스'는 롱온리 도구론 불가(구조적)·변동성타게팅으로 완화만.

## 4. 정직성/방법론 (왜 이렇게 결론냈나)

- **다기간 + OOS + 종목별 승률**로 판정. 단일창 in-sample은 매번 과최적.
- **교차 엔진 확인**이 거짓양성 잡음(모멘텀 룩백 하네스 vs verify 정반대).
- **생존편향**: 상폐종목 데이터 없어 절대수익은 낙관상한. 코드로 못 고침·상대알파+추세장한정만 믿음. S&P500 규칙기반이 손픽보단 정직(단 현 구성종목이라 잔존).
- **소액 원칙**: 규모와 알파 반비례. 집중+규율+공짜 신호개선이 답·대형 흉내(과분산/다시장) 금물.
- 헤드라인 +30%p·19.7배는 유니버스/생존편향 부풀림. **진짜 = +20%p·추세장 한정.**

- **개별주 타이밍 전 전략 전멸**(1차 배터리 14종·B&H 승률 최고 49%): 터틀 20/10·30/10·SMA off(승률 31~33%·"고변동 일방추세주 터틀" 가설 포함 기각)·52주신고가·골든크로스·절대모멘텀 개별적용·RSI30 반등·볼린저 2.0/2.5σ·5일 낙폭반등·역배열 단독 전략화.
- **변동성 돌파(k=0.5)**: 회전 104회/년 → 거래세에 즉사(Calmar 0.01) — 국내 현물에서 고회전 단타는 구조적 불가.
- **Connors RSI2(>200MA) 승격 실패**: MDD 28% 방어형이나 CAGR 3.1%로 실익 없음(거래세가 얇은 엣지 잠식 — 예상 적중).
- **z-스크리너(변동성+모멘텀) = 소수 종목 환상**: 슈퍼위너 제외 시 ×5.04→×1.39(+9.4%p) 붕괴. 미국(+30%p 보수검증 유지)과 달리 한국 55종 유니버스에선 비강건.
- **지수 절대모멘텀 필터(KOSPI 12M) = 대참사**: 84.9x→8.7x·2022 방어도 실패(후행이라 2023 반등 초입 통째 상실) — 미국 레짐필터(200MA) 무효와 동형.
