# 차트 매매 신호 검증 — 미국 시장 약형 효율적시장가설 검정과 매매 규칙 재설계

제가 쓰던 차트 매매 신호(SMC 계열: FVG·오더블럭·추세선 등, 이하 'BATTO v1')에 미래 수익을 예측하는 정보가 있는지 통계로 검정한 기록입니다. 결과는 "미국 시장에서는 효과가 없다"였고, 그 결과를 받아들여 남은 신호로 매매 규칙을 다시 만들고 다른 기간·다른 종목군에서 다시 확인했습니다.

- 기간: 2026년 6~7월 연구, 데이터는 2007~2026년(분석마다 다름)
- 판정 원칙: 한 구간에서 좋아 보이는 결과는 믿지 않고 **무작위 진입 대비 · 검증 구간(OOS) · 여러 기간 · 종목별 승률**로 판정 (`docs/BATTO_연구로그.md` 4절)

## 1. 차트 신호 검정 (`emh/`, `batto/benchmark_entry.py`, `batto/robustness_fng.py`)

| 분석 | 대상 | 횟수·표본 | 결과 |
|---|---|---|---|
| 지수 회귀 (Newey-West) | S&P500·코스피200·비트코인, 2015~2025 | 6신호 × 3시장 × 보유기간 3 = 54회 | 전부 유의하지 않음(max\|t\| 1.61), FDR 보정 뒤 통과 0건 |
| 개별 종목 패널 (이중 클러스터) | 141종목(미국 79·한국 40·코인 22) | 시장마다 18개 검정 | 미국 유의 0건. 코인 FVG만 5일 +0.69%p(p<.001) |
| **진입 비교** | S&P500 503종목, 2021~2026, 롱 | 신호 2,308번 / 무작위 50,200번 / 공포탐욕지수 30 미만 131,456번 | 40일 수익률: **신호 − 무작위 = +0.05%p (t 0.20)**, 공포지수<30 − 무작위 = +1.90%p |

결론: 신호로 산 수익은 아무 날에나 산 수익과 같았습니다(미국 시장 약형 EMH 지지). 견고하게 남은 것은 시장 전체의 공포가 극단일 때 사는 신호 하나였습니다. 전체 수치는 `docs/전체분석기록.md`에 있습니다.

## 3. 한계

- **생존편향**: S&P500은 지금 구성 종목으로 돌렸고 상장폐지 종목 시세가 없습니다. VIX 분석의 70종목도 2026년 시총 상위 종목입니다. 그래서 절대수익은 부풀려져 있고, **무작위 진입·같은 종목 아무 날 대비 차이**만 판단에 썼습니다. 연구로그에도 "헤드라인 +30%p·19.7배는 부풀린 숫자, 진짜는 +20%p·추세장 한정"이라고 적어 두었습니다.
- 공포탐욕지수 데이터는 2021~2026년뿐이고, 보유 기간이 겹치는 데서 생기는 자기상관은 HAC로 보정하지 않았습니다(연도별 일관성으로 보완).
- 모두 백테스트입니다. 실계좌 성과가 아닙니다.

## 5. 재현

시세·지수 데이터는 넣지 않았습니다(데이터 제공처 약관). 아래 스크립트로 받습니다.

```bash
pip install -r requirements.txt
python batto/fetch_sp500.py       # S&P500 구성 종목 + 일봉
python batto/fetch_fng_stock.py   # CNN 공포탐욕지수
python emh/fetch_data.py          # 1단계 지수·종목 데이터
```

일부 스크립트는 원래 작업 폴더에서 만든 캐시 파일(종가 묶음 `.pkl`, VIX 장기 CSV 등)을 읽어서, 받은 데이터만으로는 바로 돌지 않을 수 있습니다. 결과는 각 로그와 `results/`에 남아 있습니다.

## 만든 방법

AI 코딩 도구(Claude Code)를 사용해 만들었습니다. 검정할 질문과 판정 기준을 먼저 정하고, 실패한 결과도 로그에 그대로 남겼습니다.
